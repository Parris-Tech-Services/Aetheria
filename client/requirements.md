## Packages
framer-motion | Page transitions, screen shake, and smooth UI animations
clsx | Utility for conditional class joining
tailwind-merge | Utility for merging tailwind classes safely
zustand | Lightweight state management for complex game loop state

## Notes
The game uses a strict 'parchment and iron' dark fantasy aesthetic.
Dynamic images are not needed, all visuals are CSS, Canvas particles, or text-based sprites.
