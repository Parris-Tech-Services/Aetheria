## Replit Upgrade Prompt

```
You are an expert game developer, systems designer, and narrative designer.

First, scan and understand the ENTIRE project before making changes. Analyze:
- project structure
- existing game mechanics
- map system
- NPC system
- dialogue system
- quest system
- combat or interaction mechanics
- lore and story elements
- UI components
- backend logic
- data structures

The project is called "Aetheria: Whispering Woods". Your goal is to MASSIVELY expand and upgrade it while keeping the existing game functional.

Do NOT remove existing working systems. Instead expand and improve them.

After analyzing the project, implement the following upgrades:

--------------------------------

1. EXPAND THE WORLD MAP

Create multiple new explorable regions connected to the Whispering Woods.

Examples of regions to add:
- Ancient Ruins of Elyndra
- Moonlit Marsh
- Emberfall Mountains
- The Crystal Hollow
- Sunken Temple of Vaelor
- Frostveil Tundra
- Skyroot Canopy (treetop civilization)
- The Obsidian Rift

Each region should include:
- unique terrain
- environmental descriptions
- enemies or creatures
- hidden locations
- collectible lore items
- environmental storytelling

Add a world map system if one does not exist.

--------------------------------

2. ADD MANY NEW NPCs

Create at least 25–50 new NPC characters.

Each NPC should have:
- name
- personality
- role (merchant, wanderer, hunter, scholar, mystic, etc.)
- dialogue tree
- possible quests
- reactions to player choices

Include special NPC types:
- travelling merchants
- mysterious strangers
- faction leaders
- storytellers
- hidden characters
- rare encounter NPCs

--------------------------------

3. DEEP DIALOGUE TREES

Upgrade the dialogue system to support:

- branching dialogue
- multiple player responses
- persuasion / intimidation / curiosity options
- hidden dialogue options
- reputation-based dialogue
- quest-triggering dialogue

Each NPC should have at least:
- 6–10 dialogue branches
- conditional responses
- story/world lore

--------------------------------

4. QUEST SYSTEM EXPANSION

Add multiple quest types:

Main quests
Side quests
Exploration quests
Mystery quests
Faction quests
Hidden quests

Each quest should include:
- objectives
- rewards
- branching outcomes
- story impact

Add at least:
- 20+ side quests
- 5+ major questlines

--------------------------------

5. LORE EXPANSION

Expand the world lore significantly.

Create:

Ancient history of Aetheria
Legendary heroes
Lost civilizations
Magical artifacts
Myths and prophecies
Regional conflicts
Secret factions

Distribute lore through:
- NPC dialogue
- books
- ruins
- artifacts
- hidden notes

--------------------------------

6. FACTIONS

Introduce factions such as:

- The Verdant Circle
- Order of the Ember Crown
- The Silent Archivists
- The Moonveil Nomads
- The Obsidian Covenant

Add:
- faction reputation system
- faction quests
- faction NPCs
- faction conflicts

--------------------------------

7. WORLD EVENTS

Add dynamic events like:

- wandering traders
- monster attacks
- traveling storytellers
- lost travelers
- magical anomalies
- rare boss encounters

--------------------------------

8. ENEMIES & CREATURES

Create many new creatures based on regions.

Examples:
- moss wolves
- ember drakes
- crystal golems
- swamp wraiths
- frost revenants
- sky serpents

Include:
- stats
- behaviors
- loot tables

--------------------------------

9. HIDDEN SECRETS

Add discoverable secrets:
- hidden caves
- secret bosses
- puzzle ruins
- buried artifacts
- secret NPCs

Reward exploration heavily.

--------------------------------

10. PLAYER PROGRESSION

If not already present, implement:

- player leveling
- skills
- abilities
- equipment
- rare items
- legendary artifacts

--------------------------------

11. UI IMPROVEMENTS

Improve the UI with:
- map navigation
- quest log
- dialogue interface
- NPC interaction panels
- inventory system

--------------------------------

12. CODE QUALITY

Refactor code where needed to support scalability.

Ensure:
- modular design
- reusable systems
- clear data structures
- separation of world data, NPC data, quests, and dialogue

--------------------------------

13. CONTENT SCALE TARGET

The finished upgraded project should include approximately:

- 8+ regions
- 50+ NPCs
- 30+ quests
- 200+ dialogue lines
- deep lore for the world
- hidden secrets across the map

--------------------------------

Important:

1. Do NOT break existing functionality.
2. Build systems that are easy to expand later.
3. Use clean data-driven structures where possible.
4. Add comments explaining new systems.

After implementing upgrades, provide a summary of:
- new systems added
- new regions
- NPCs created
- quests added
- lore introduced
```
